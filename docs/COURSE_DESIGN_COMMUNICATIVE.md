# B1 / B2 course design v2: learner-centred, communicative, exam at the end of every module

Owner 2026-10-16: „сделать интересный и эффективный курс B1 и B2, чтобы листы были разные и разнообразные, по
принципу õpijakeskne tund и коммуникативному методу, с экзаменационными заданиями в конце модуля”. Decisions: pilot
first (B1 module 13, B2 module 02), the topics and the grammar line stay, the module ends with a mini Harno exam in
all four skills. This file is the contract for every module written in design v2 (`MODULE.design: 'v2'`).

## 1. Why the old sheets felt like templates (measured 2026-10-16, 1090 course sheets)

- 3 of 4 Avasta / Kasuta sheets opened with „text → reading questions” or „text → Märka!”: the level gate demanded a
  140 / 220-word text in both phases, so every phase got one.
- Every sheet had a self-check (1091) and a speaking block (1050); 12 block types made ~70 % of all blocks; the
  picture blocks, the word search, the clock, phrase banks, profiles, diagrams, dialogues were (almost) never used.
- The depth gate (≥ 10 items per closed task, ≥ 25 min of drills) added one more drill instead of one more kind of
  thinking. Phases repeated the same facts (questions + true/false on one text) and Kasuta asked for 2–3 similar texts.

## 2. Principles

**Õpijakeskne (learner-centred).** The learner's own life, opinions and choices are the material: they choose (one of
two situations, a role, a topic card), compare with a partner, set and check their own goal. The sheet asks „what do
*you* …”, not only „what did Anna …”. Self-assessment is concrete (one can-do, one next step), not a ritual on every
sheet. Personal data is never required: „you may invent the details”.

**Communicative.** Language is used to do something with someone: an information gap (A knows what B needs), a
decision to reach, a problem to solve, a message with a real addressee. Accuracy work serves that task and comes right
before it. Every lesson ends with the learner doing the can-do, observably.

**Variety by design.** The phase decides the *job*; the input and the tasks rotate. No two consecutive lessons of a
module open the same phase the same way; one module uses most of the constructor's block families.

## 3. The three phases

| Phase | Job | Typical length | Ends with |
|---|---|---|---|
| **Avasta** (discover) | meet the situation, understand it, *notice* the language that does the job | 40–50 min | the learner states the rule / pattern in their own example |
| **Harjuta** (practise) | make the new form and the phrases automatic, in *varied* operations (form → choice → sentence → mini-dialogue) | 40–50 min | a short guided interaction or text using the pattern |
| **Kasuta** (use) | one realistic task with a result: agree, decide, complain, plan, advise, apply | 40–55 min | one assessed product (rubric), optionally one oral and one written, with different functions |

**Avasta — input menu (rotate, one per lesson):** reading text · dialogue in bubbles (`dialogue`) · listening
(TartuNLP audio) · people profiles to compare (`profiles`) · a timetable / price list / table · a message thread
(dialogue or reading in chat form) · an ad or notice set (`manymatch`) · a diagram of a process (`diagram`) · a short
story told in pictures · a quiz on the learner's own habits (`choice` about themselves, then a text).
After the input: **one** comprehension task (gist or detail — not both on the same facts), **one** noticing task
(`notice` + `categorize` / `match` / `table`), a first guided use (`transformation`, `dialogue` gaps, a mini speaking
turn about themselves).

**Harjuta — operation families (use ≥ 4 different families, ≥ 6 items each):**
form (`wordforms`, `table`, `crossword`) · choice (`choice`, `cloze`, `gaps` with a bank) · order and structure
(`wordorder`, `categorize`, `manymatch`) · whole sentence (`transformation`, `errorfix`, `translation`) · listening and
writing (`dictation`, `listening` with gaps) · interaction (`dialogue` gaps, `rolecards` short).
Errors in `errorfix` are only errors Russian speakers really make and that are wrong in standard Estonian (check EKI:
*sest et*, *kell kolmel*, *terve päev* are correct — never mark them).

**Kasuta — task menu (rotate):** role play with an information gap (`rolecards`) · negotiation to one decision
(`profiles` / options + speaking) · problem → solution (`planning` → `letter`) · complaint or request (`letter`) ·
choose and justify (`table` of options → speaking) · survey a partner and report (`table` → writing) · advice column
(reading → letter) · a mini-project (plan + present). Each Kasuta has a short preparation (phrase bank or planning),
the task, one rubric for the product(s) actually produced. No new long reading text in Kasuta unless the task needs it
(a notice, an offer, a short letter to answer).

## 4. Module shape (5 lessons)

Lessons 1–4: topic lessons (Avasta → Harjuta → Kasuta each). Lesson 5: **„Eksam”** — the mini Harno exam of the
module, in the module's topic and vocabulary:

| Sheet | B1 (Harno B1 formats) | B2 (Harno B2 formats) |
|---|---|---|
| Avasta = *Korda ja valmistu* | a fast, game-like review of the module (crossword, match, quiz about the learner), the exam's format explained | same |
| Harjuta = *Lugemine ja kuulamine* | reading: situations ↔ notices (6–9), text + 6 multiple choice, cloze 8–10; listening: 2–3-min monologue + 6 choices, dialogue + gap sentences | reading: article + 6–7 choices, 8 statements ↔ paragraphs, cloze with 4 options; listening: talk + 5 choices, lecture + gap sentences (1–2 words), interview + T/F |
| Kasuta = *Kirjutamine ja rääkimine* | writing T1 note ~50 words (4 points) and T2 personal letter ~100 words; speaking: questions + agreement task + phone role play | writing T1 semi-formal letter ~140 words and T2 argument / summary ~180 words; speaking: 1-min monologue + discussion to a joint position |

Every exam part shows its points; the closed parts are scored by the sheet, writing and speaking by the rubric
(4 criteria × 0–3 points). The module's aim: **≥ 60 % in each skill**; below that the teacher repeats that skill's
part of the module (the sheet's per-goal score shows it: `g_read` = reading and listening, `g_use` = writing and speaking).

## 5. Variety rules (checked by `didactics/variety.js` for `design: 'v2'` modules)

- No two consecutive lessons open the same phase with the same block type (after an optional `text` / `tip`).
- Two lessons of a module share at most 60 % of the same block-type sequence in one phase.
- A module uses ≥ 16 different block types; every phase type has ≥ 4 operation families.
- A self-check at most once per lesson (Kasuta); speaking where the task needs it, not on every sheet.
- The input-text rule accepts any input of the length: reading, listening transcript, dialogue, profiles, cloze.

## 6. Depth norms for v2

Closed tasks ≥ 6 items (B1) / ≥ 6 (B2) — several shorter, different operations are better than one long drill;
exercises ≥ 25 min in Avasta and Harjuta still hold (interaction tasks with a key — dialogue gaps — count). Kasuta:
≥ 12 min of preparation exercises, the task carries the rest. Sheets 40–55 min.

## 7. Process

One module = one branch and PR; module report READY (structure, depth v2, keys, level, uniqueness, vocabulary,
variety); language check 0 unknown words; listening audio built with `tools/listening-audio/build.mjs`; the owner tries
the pilot in a lesson before the rest of the course follows.

## 11. Lesson template v3 (owner 2026-10-18: „столько блоков не надо”)

Why: a lesson had 30–35 blocks of ~5 items, 11–18 of them drills; little monologue, few situations, almost no exam
text tasks. Sources: the three-part lesson (häälestus → põhiosa → kokkuvõte; Integratsiooni Sihtasutus
„Keeleõpetaja metoodikavihik”), Willis' task cycle (language focus after the task, on its text), Nation's four
strands (≈ a quarter of the time each for input, output, language study, fluency), Harno B2 consultation booklet
(reading 3: a text with 12 gaps, options A–D; reading 4: sentences into a text, one extra; listening: 1–2 words;
writing ~140 + ~180 words; speaking: a speech, questions, a situation with pro / contra cards).

`template: 'v3'` on the lesson or `MODULE.template: 'v3'` (registry → `meta.template`; the module keeps
`design: 'v2'`). Pilot: B2 lesson b1b2-061.

| Sheet | 5–9 blocks (the textbook picture not counted), ≥ 4 task types, 40–55 min |
|---|---|
| Avasta | opening → a text to think about (B2: 300–450 words, fact questions) → the language noticed in it (notice) → one full language task (10–12 items) → a pair discussion with opinion questions → (short writing) |
| Harjuta | the exam's text tasks: `cloze` (12 gaps, A–D) + `formtext` („Pane sõnad õigesse vormi” in a text) + one more exam text (`insertion`, listening, Harno info reading, choice / matching) → plan → monologue |
| Kasuta | situation → input text → `rolecards` with pro / contra arguments (Harno style) → a speech (`speaking`) → letter or essay → rubric (→ the lesson's one self-check) |

Lesson balance (quality.js `balanceProblems`): sentence and form drills ≤ 40 % of the lesson's minutes, speaking and
writing ≥ 25 %; exam text tasks count as reading. Closed tasks have the level's full item count (B1 / B2 ≥ 10).
Module: ≥ 12 block types, neighbours share ≤ 85 % of task types (the template repeats on purpose; the order and the
third exam task rotate), consecutive lessons open differently.

New blocks (engine/blocks/exam.jsx): `formtext` — „Eile [käisin] (käima) poes.”, accepted forms in brackets, the base
form after them; `insertion` — the whole text with taken-out sentences in `[[…]]` and `extra` sentences, letters A–…
on paper, a select per gap on screen. Builders `B.formtext`, `B.insertion` (course/blocks.js).

Gate changes: gates.js speaking length B2 180 s, C1 210 s (was 240 / 300 — above the didactic norm, every B2 sheet
with a monologue failed one of the two checks). depth.js v3: Avasta exercises ≥ 12 min, Kasuta ≥ 6 min (the sheet is
speaking and writing), no sentence-writing rule (the exam text tasks replace it).

## 12. Lesson template v4 (owner 2026-10-22: „много диктантов и исправления ошибок, разнообразия и ситуаций не хватает”)

v3 fixed the task list of each phase (Avasta: text + notice + language task + talk; Harjuta: cloze + formtext + an
exam text + a monologue; Kasuta: role cards + speech + letter). Together with the depth rule „two whole-sentence tasks a
sheet” it pushed every lesson to the same drills (error correction, translation, dictation). v4 keeps v3's sizes
(5–9 tasks, 40–55 min, the level's item counts) and replaces the fixed list with variety rules (`quality.js`
`v4Problems`, `v4ModuleProblems`):

- **Module:** one storyline with the course's characters and a goal said on the first sheet (B1 module 5: a story for the
  town paper's contest, written and judged in the last Kasuta). **Amended 2026-11-02 (§13):** the cast may stay as the
  module's thread, but it is no longer the only content — every lesson also has a text from a voice outside the cast and
  a discussion wider than the episode, and every module opens its Harno topic with real facts. At least 2 listening tasks; error correction ≤ 2,
  translation ≤ 1, dictation ≤ 2 a module (exam lessons not counted); a form or sentence drill once a lesson.
- **Avasta:** an input to think about (reading, listening, chat, character cards, picture) → notice → find the rule
  (table, categorize, timeline) → talk. No error correction, translation or dictation before the form is met.
- **Harjuta:** a ladder of different tasks, a type at most once a sheet, at most two form / sentence drills; ends in use
  (role play, information gap, monologue, writing).
- **Kasuta:** a real situation with someone to talk to and a result (doctor's appointment, radio interview, a story for
  a contest); no form or sentence drills at all.

Added 2026-10-22 (docs/METHODOLOGY_STANDARD.md): Avasta starts with „Mäletad?” — 2–3 min of review of the previous
lesson (`B.review`, not counted among the tasks; gate `v4-review`); a pair or group task and every role play carries a
one-to-one note for the teacher (`teach(block, 'Üks-ühele: …')`, shown in the teacher's key „Õpetajale”; gate
`v4-one-to-one`). The level's grammar and where it is taught: `admin/course/grammarPlan.js` (test lists the gaps).

Sample: `admin/course/b1/module05.js` (the v3 file is in `archive/v3/b1/module05.js`). Set `template: 'v4'` in MODULE.

## 13. Academic value: the topic, the world and the learner's opinion (owner 2026-11-02)

Owner 2026-11-02: „привести все модули в порядок, повысить их академическую ценность … каждый лист — это урок, он должен
быть интересным и полезным, а блоки — красивыми, как страница учебника”; earlier: the textbook goes too deep into one
concrete situation and gives no food for thought; it should cover the exam topics and the use of language more broadly,
so the learner gets not only words but general knowledge and experience of talking about different topics. The owner
approved changing the module plan and the „one storyline per module” rule (§12, amended). The template (v4) and every

### 13.2 The module topic opener („Teema avaleht”)

One per module, on lesson 1's Avasta sheet (lesson 2's when lesson 1 is an entry test), built with
`B.topicOpener(id, heading, paragraphs, source, questions)`: 200–350 words at B1, 300–450 at B2, **no cast character**,
real facts about Estonia and the world, the source line „Allikas: …” (Statistikaamet, ERR, Harno, a ministry, a museum,
an encyclopaedia — a source a reader can find), then 3–4 „Mõtle kaasa” questions that ask an opinion or a comparison,
one of them Estonia vs the learner's home country („Kuidas on see sinu kodumaal?”). Facts are checked against the named
source at writing time; when in doubt, round („üle 2000 saare”) and name the year. The opener is a `text` block: it
counts among the sheet's 5–9 blocks and adds reading time, so the sheet may need one task fewer.

### 13.3 Every lesson is a real lesson

Each teaching lesson (not the module's exam, an oral or a diagnostic lesson) has:

- **a clear goal** — its canDo (lessonGoals.js);
- **a text from a non-cast voice** — an article, interview, expert, forum, news item, infographic (`B.chart` with its
  source), a fiction or popular-science excerpt — at least 80 words at A2+, 120 at B1- / B1, 150 at B1+, 180 at B2- / B2,
  with no cast name. Label it with `tag(block, { voice: 'article' | 'opinion' | 'interview' | 'expert' | 'forum' | 'news' |
  'infographic' | 'fiction' | 'popsci' })`; the B1 course counts the popsci and fiction labels;
- **an opinion / discussion speaking task on a question wider than the episode** — a speaking, card or role-play question
  with no cast name that asks what the learner thinks, compares, argues or relates it to Estonia / their home country;
- **something new to know** — a fact, a cultural point or a useful real-life procedure: `B.know(id, text, source)`
  („Kas teadsid?”), the topic opener, or a non-cast text with its source line.

The cast may carry the module's thread (a story to finish, a decision to make), but it is the frame, not the whole
content. A cast scene stays valuable when it shows a real procedure (registering with a family doctor, a tenancy contract).

### 13.4 Variety limits per module

- 3-2-1 / 4-3-2 retelling at most **1** a module (other fluency tasks: a timed opinion, speed reading, a picture talk).
- „Record it at home” speaking tasks („salvesta”, „lindista”) at most **2** a module.
- Kasuta: at most **half** of the module's Kasuta sheets follow „voicemail or phone call → letter”; the others use the §3
  task menu (negotiation, survey and report, advice column, mini-project, debate, presentation, a plan to choose).
- Task types stay varied as before (§5, §12).

### 13.5 Exam-like reading

- B2: every module has one cast-free **500–600-word opinion or problem article** (the Harno B2 main reading; it may be the
  `reading`, `insertion` or `cloze` text, in paragraphs).
- B1: across the course at least **4 popular-science** and **4 fiction excerpts** (`voice: 'popsci'` / `'fiction'`), adapted
  to the level, with the author or source named.

### 13.6 Facts are real

A number presented as a fact (a percentage, or a figure with „uuring”, „küsitlus”, „statistika”, „andmetel”,
„keskmiselt”, „rahvaloendus”, „prognoos”) carries a source line in its block („Allikas: …”; a chart's own source field).
Invented numbers may appear only inside a clearly fictional cast scene (a block that names the cast). Exam targets
(„vähemalt 80 % igas osas”), shop discounts and questions are not facts.

### 13.7 Speaking breadth

Each module has an examiner-style question set on its Harno topic: one speaking block with 6–8 cast-free questions, at
least 2 of them asking an opinion or a reason — B1 speaking part 1 style; at B2 the one-minute talk on the topic followed
by the discussion questions (`B.examiner(id, topic, questions, 'B1' | 'B2')`).

### 13.9 Round 2: what round 1 let through (learner's-eye review, 2026-11-03)

A review of the finished B1 course read as a learner found: ~10 of 36 sampled lessons are an unchanged cast episode plus
a 50–100-word fact box; topic openers read like statistics dumps (30 numbers in 242 words); „sinu kodumaa” in 63 lessons,
though many learners were born in Estonia; Kasuta still mostly a phone call (62 / 90) and call + letter (44 / 90); the
retelling in other words („esimest korda kolme, teist korda kahe minutiga”) 24–29 times against 18; one radio host
(„Ülle”) in 51 lessons; the same facts in several modules (ID card / e-services, the right to roam, „Teeme ära!”); the same
four „Mõtle kaasa” questions everywhere. The rules below add to §13.2–13.7; the work order is
`docs/ACADEMIC_VALUE_ROUND2.md`.

- **A lesson is not an episode + a fact box.** Each teaching lesson has a main text from outside the story of the stage's
  length (§13.3 lengths): an article, interview, expert, news item, forum, fiction or popular-science excerpt. A „Kas
  teadsid?” box, a tip, a chart or the opener does not count; the radio host „Ülle” counts as cast.
- **The opener is a page to read, not a table:** at most **8 numbers** (digits, years, percentages) in its body; keep
  the 3–5 that matter, say the rest in words („üle poole”, „iga kolmas”) or move them into a chart.
- **„Mõtle kaasa” varies:** each opener's questions are of at least **3 kinds** (reaction, experience, opinion,
  comparison / another country, prediction, problem-solving); across a course the home / other-country question sits in
  the same slot in at most a third of the openers, and no sequence of question kinds repeats in more than 3 openers.
- **Not everyone has a „kodumaa”.** The word in any case at most **2 times a module**. Ask in ways that fit a learner born
  in Estonia too: „mõnes teises riigis”, „riigis, mida sa hästi tead”, „mujal maailmas”, „sinu kodukohas”, „seal, kus sa
  üles kasvasid”. The opener's comparison question (§13.2) may use these.
- **One repeated retelling a module, in any wording:** 3-2-1, 4-3-2, „kaks / kolm korda”, „esimest korda … teist korda”,
  „teisel korral”, „iga kord lühemalt / kiiremini”, „kolmele kuulajale”, „uuele paarilisele”, „uuesti … ilma märkmeteta”,
  „mitu korda järjest” (speaking and card tasks).
- **Kasuta without the phone:** at least **half** of a module's Kasuta sheets have no phone task at all (telefon, helista,
  häälsõnum, kõnepost, videokõne, „kõne” + a case ending such as „kõne klienditeenindusse”, a phone card), and at most half
  end with a letter or e-mail.
- **More voices:** one recurring voice (a cast member or the radio host) opens at most **2** listening texts a module, and
  every module with listening has at least one listening text with no recurring voice — news, an interview, a street poll,
  an expert (stage length or a `voice` tag).
- **A fact once.** The same fact does not come back in another module of the B1 or B2 course (a near-duplicate sentence in
  two fact texts, or a key fact from `FACT_KEYS`: X-tee, igaüheõigus, „Teeme ära!”, ID card + mobile-ID / Smart-ID,
  e-residency, digital signature, e-voting, Baltic Way, Skype). Choose another fact, or refer back („Mäletad, …”) without
  restating it.

**Gates** (`academicValue.js` round-2 section, thresholds `AV2`, run by `academicValueRound2Gate.test.js` with its own
baseline `academicValueRound2Baseline.json`; round 1's gates and baseline are unchanged):

| code | scope | rule |
|---|---|---|
| `av-boltedon` | lesson | a cast-free main text of the stage's length; fact box, tip, chart, opener and „Ülle” do not count |
| `av-opener-numbers` | module | ≤ 8 number tokens in the opener body („450 000” is one, „2019–2021” two) |
| `av-thinkvary` | module | the opener's questions are of ≥ 3 kinds |
| `av-thinkvary` | course | home-country question in the same slot ≤ ⅓ of the openers (at least 2 allowed); same kind sequence ≤ 3 openers |
| `av-retell2` | module | repeated retelling in any wording ≤ 1 (round 1's `av-retell` broadened) |
| `av-kasuta2` | module | ≥ half of the Kasuta sheets with no phone task; ≤ half ending with a letter / e-mail |
| `av-homecountry` | module | „kodumaa” (any case) ≤ 2 |
| `av-voices` | module | ≤ 2 listening texts opened by the same recurring voice; ≥ 1 listening text without one |
| `av-fact-dup` | course (B1 + B2) | no key fact and no near-duplicate fact sentence (Jaccard ≥ 0.4 on 6-letter stems, ≥ 6 stems; numbers must overlap; 0.6 when only one side has a figure) in a second module |

Round 2 also widens round 1's home-country cue (`HOME`) with the wordings above, so the opener gate accepts them.
