# KeeleSepp CEFR-aligned A2 → B1 learning standard

Status: internal normative document  
Scope: Eesti keel · B1 õppekava · A2 → B1 õpitee  
Roadmap: 18 modules / 90 lessons  
Core lesson phases: **1 Avasta → 2 Harjuta → 3 Kasuta**

> This is a KeeleSepp internal CEFR-aligned implementation standard. It does not replace the official CEFR descriptors. It defines what must be taught, recycled and demonstrated at each stage of the KeeleSepp A2→B1 pathway.

## 1. Progression contract

| Lessons | Stage | Expected learner behaviour |
|---|---|---|
| 001–020 | A2 | Short functional answers; 3–6 connected sentences; familiar situations; high support. |
| 021–040 | A2+ | 6–10 connected sentences; short narratives; reasons; more independent form choice. |
| 041–060 | A2+/B1- | 2–3 minute connected speech; comparison; problem solving; less direct support. |
| 061–080 | B1- | 3–4 minute interaction; alternatives, compromise, conditions, reasons and examples. |
| 081–090 | B1 | Functional reading/writing and sustained spoken production with clear structure and independent language choice. |

### Non-negotiable difficulty rule

A worksheet must match the lesson's levelStage, not only the curriculum label “B1”.

- A2: recognition + short controlled production.
- A2+: controlled choice must require form/meaning decisions, not only copying.
- A2+/B1-: tasks must require paraphrase, reason, comparison, transformation or problem solving.
- B1-: tasks must require multi-sentence justification, reaction to new information and reduced scaffolding.
- B1: tasks must require independent structure, inference, reformulation and transfer.

A task that can be solved by copying one obvious word from a visible word bank is **not sufficient for A2+/B1- or above**.

## 2. Three-phase lesson architecture

Every normal lesson is developed as a set of three separate worksheets using the same communicative goal, grammar spine and lexical cycle.

### 1 Avasta — notice and understand

Purpose: first meaningful encounter with the lesson target.

Required:
1. activation / prior knowledge;
2. vocabulary support;
3. natural text/dialogue/scenario;
4. gist comprehension;
5. detail + inference comprehension;
6. language noticing from examples;
7. short controlled first use;
8. small personal production;
9. self-check.

Rules:
- 7–9 substantial blocks.
- Reading text normally 100–180 words at A2+/B1-, longer later.
- Question sets normally **minimum 5 items**.
- Reading questions must not be only literal “find the same sentence” questions.
- A set should normally include 1–2 factual items, 1 paraphrase item, 1 cause/effect item and 1 inference/interpretation item.
- Vocabulary and grammar are discovered in context before explicit drilling.

### 2 Harjuta — accuracy and controlled flexibility

Purpose: stabilise vocabulary, grammar and functional patterns.

Required:
1. short retrieval from Avasta;
2. form recognition;
3. transformation;
4. controlled production;
5. error correction or contrast;
6. mixed practice with previous module material;
7. short oral micro-task;
8. exit check.

Rules:
- No passive repetition of Avasta.
- At least two tasks must require transformation rather than selection.
- At A2+/B1- and above, word banks are optional support, not the main solving mechanism.
- Grammar tasks must use the module vocabulary and real communicative context.
- Include deliberate recycling from previous lessons.

### 3 Kasuta — independent transfer

Purpose: use the target in a new situation with reduced support.

Required:
1. retrieval warm-up without visible answers;
2. one authentic scenario / role / problem;
3. extended speaking or dialogue;
4. short writing or mediation task where appropriate;
5. unexpected condition / change / extra constraint from B1- upward;
6. self-evaluation against the “Ma oskan…” goal.

Rules:
- No full model answer visible before production.
- Learner must choose vocabulary and grammar independently.
- At A2+/B1-: at least one task must require reason, comparison, alternative or repair.
- At B1-: one task must change conditions mid-task.
- At B1: one task must require reformulation, inference, mediation or structured argument.

## 3. Lexical recycling standard

### 3.1 Active vocabulary size

Default active target per module:
- **12–16 core lexical items / chunks**
- up to **6 secondary items** for recognition/support
- assessment lesson introduces **no new core vocabulary**

### 3.2 Recycling ratio inside a 5-lesson module

| Lesson | New core items | Recycled from same module | Recycled from previous module |
|---|---:|---:|---:|
| 1 | 8–10 | 0–20% | 20–30% |
| 2 | 4–6 | 50–60% | 20–30% |
| 3 | 2–4 | 60–70% | 20–30% |
| 4 | 0–3 | 70–80% | 20–30% |
| 5 Kontroll | 0 | 85–100% | 20–30% |

A core item is not “learned” after one appearance.

### 3.3 Minimum encounter rule

Every module-core lexical item should appear in at least:
1. one receptive context;
2. one controlled task;
3. one productive task;
4. one later retrieval task.

Preferred: reappear in **at least 3 lessons of the same module** and once again in the following module.

### 3.4 Spaced return

Priority vocabulary should return approximately:
- same lesson: Avasta → Harjuta → Kasuta;
- next lesson;
- lesson +2 or +3;
- module assessment;
- next module in a mixed retrieval task.

### 3.5 Vocabulary display format

All vocabulary blocks must show forms + Russian translation.

**Verb**
- magama – magada – magan — спать
- liikuma – liikuda – liigun — двигаться

**Noun**
- harjumus – harjumuse – harjumust — привычка
- puhkus – puhkuse – puhkust — отдых

**Adjective**
- tervislik – tervisliku – tervislikku — полезный для здоровья / здоровый

**Fixed phrase / chunk**
- piisavalt magama – piisavalt magada – magan piisavalt — достаточно спать
- vett jooma – vett juua – joon vett — пить воду

No vocabulary block may be only an untranslated one-form list.

## 4. Typography and visual learning support

### No empty instructional space

Large empty zones are not allowed if they can carry useful learning support.

A free half-page/column should contain one of:
- **Vihje** — hint;
- **Näide** — example;
- **Reegel** — concise rule;
- **Sõnavara** — lexical support;
- **3 vormi + tõlge**;
- mini-schema / timeline / contrast;
- micro-retrieval task.

Support must be relevant to the neighbouring task and must not reveal the entire answer.

### No raw Markdown markers

Learner-visible text must not contain raw asterisks, underscores or other authoring syntax.

New vocabulary / target forms should be highlighted using the worksheet renderer:
- bold;
- semantic accent;
- labelled language box;
- controlled inline emphasis.

## 5. Reading and comprehension standard

Texts must contain the vocabulary and grammar target naturally.

### A2
- mostly explicit information;
- short paragraphs;
- questions can include factual retrieval but not only copying.

### A2+
- some paraphrase required;
- simple cause/effect;
- sequence and intention.

### A2+/B1-
- fewer identical lexical matches between question and source sentence;
- inference from two pieces of information;
- reason / consequence;
- classify or choose best summary.

### B1-
- author/speaker intention;
- implicit reason;
- compare alternatives;
- infer attitude or likely next step.

### B1
- distinguish main point vs supporting detail;
- paraphrase;
- infer purpose/position;
- integrate information across the text.

**Minimum question count for a question-based comprehension block: 5.**

## 6. Controlled practice difficulty

### A2
Allowed:
- matching;
- simple choice;
- guided gap fill;
- reorder;
- short model-based answer.

### A2+
Required progression:
- form change;
- competing forms;
- short transformation;
- error correction;
- sentence completion where more than one semantic cue matters.

### A2+/B1-
Controlled practice should include at least two of:
- transform the whole sentence;
- choose form + explain meaning;
- repair an error;
- combine two clauses;
- complete cause/result;
- adapt language to a changed situation.

### B1-
Require:
- reduced word-bank support;
- multiple acceptable formulations;
- short context-sensitive production.

### B1
Require:
- independent reformulation;
- editing;
- register/purpose choice;
- productive use in connected text.

## 8. Example: module 1 cyclic design

### Core grammar
- present tense;
- simple sentence word order;
- frequency adverbs;
- basic time markers;
- ja / aga / siis / pärast seda.

### Core vocabulary
A stable 12–16-item everyday-life set, for example:
- ärkama – ärgata – ärkan
- sööma – süüa – söön
- minema – minna – lähen
- töötama – töötada – töötan
- õppima – õppida – õpin
- puhkama – puhata – puhkan
- koju minema – koju minna – lähen koju
- hommikul
- päeval
- õhtul
- tavaliselt
- sageli
- mõnikord
- pärast seda

### Cycle
- Lesson 001 diagnostic: receptive sample + short production.
- Lesson 002: introduce/use most daily-routine items.
- Lesson 003: same verbs + frequency + word order.
- Lesson 004: same verbs + week/time sequencing + ja/aga/siis.
- Lesson 005: no new core words; mixed retrieval and productive control.

The same principle applies to every later module.

## 9. Lesson authoring checklist

Before publication, all three sheets must pass.

### Shared
- same lesson Ma oskan… target;
- same module grammar spine;
- same core lexical set;
- lexical recycling visible across phases;
- vocabulary in 3 forms + Russian translation;
- no raw authoring markup;
- no meaningless empty areas;
- learner-visible support is useful, not decorative.

### Avasta
- 7–9 substantial blocks;
- natural context;
- minimum 5 comprehension items where a question set is used;
- includes paraphrase/cause/inference as stage allows;
- noticing before explanation;
- short independent output.

### Harjuta
- retrieval from Avasta;
- at least two transformation/error/contrast tasks;
- deliberate previous-lesson recycling;
- controlled accuracy without becoming an A2-style copy exercise.

### Kasuta
- new situation, not copied Avasta scenario;
- reduced support;
- extended speaking/dialogue;
- reason/comparison/problem solving appropriate to stage;
- changed condition from B1- upward;
- clear self-assessment.

## 10. Assessment lessons

Every fifth lesson is an assessment/checkpoint.

Assessment lesson:
- introduces no new core grammar;
- introduces no new core vocabulary;
- tests current module plus selected recycled material;
- separates language accuracy from communicative success;
- includes at least one independent productive task.

Recommended threshold from the roadmap:
- overall: 70%;
- critical skill blocks: normally not below 60%;
- later B1 readiness checks may require speaking/writing >=65%.

## 11. Implementation consequence for KeeleSepp

From this standard onward, lesson production is no longer “make Avasta first and maybe the rest later”.

A completed lesson means:
1. **Avasta published and visually checked**;
2. **Harjuta published and visually checked**;
3. **Kasuta published and visually checked**;
4. vocabulary recycling and grammar focus checked across all three;
5. student view checked for density, readability, answer space and no raw markup.

A module is complete only when all five lessons have all three phases and the assessment lesson verifies the recycled targets.

## 12. Variation standard — no repeated template

The three-phase architecture is stable, but the **exercise template must not be mechanically repeated** across lessons.

### 12.1 Principle

A module must feel coherent in goals and vocabulary, but not visually or didactically identical from lesson to lesson.

The generator/author must vary:
- task type;
- visual composition;
- interaction pattern;
- text genre;
- question format;
- support type;
- productive task format;
- order of secondary blocks.

The sequence **Avasta → Harjuta → Kasuta** remains constant, but the internal route through each phase must vary.

### 12.2 Forbidden repetition

Do not use the same sequence in every lesson, for example:

1. choice warm-up;
2. vocabulary box;
3. reading;
4. five questions;
5. notice box;
6. gaps;
7. speaking;
8. self-check.

This may appear occasionally, but not as the default template for all lessons.

Do not repeat the same:
- question wording;
- same number and layout of answer options;
- same block widths;
- same "read + answer 5 literal questions" structure;
- same speaking prompt structure;
- same controlled exercise type;
- same support box type;
- same page composition.

### 12.3 Required diversity inside one 5-lesson module

Across five lessons, use at least:
- **4 different controlled-practice formats**;
- **3 different reading/listening comprehension formats**;
- **3 different productive speaking formats**;
- **2 different writing/mediation formats** where writing is appropriate;
- **3 different support types** such as Reegel, Näide, Vihje, 3 vormi + tõlge, mini-schema, timeline, contrast table;
- **2 different page compositions** per phase.

No single activity type should dominate more than roughly one third of the module unless the grammar target specifically requires it.

### 12.4 Recommended activity pool

**Avasta**
- visual prediction;
- mini-situation;
- dialogue reconstruction;
- short article;
- message thread;
- timetable/menu/ad/notice;
- classify examples;
- notice-the-pattern;
- compare two versions;
- sequence events;
- choose best summary;
- infer likely next step;
- micro role-play.

**Harjuta**
- sentence transformation;
- error correction;
- form sorting;
- guided rewriting;
- sentence combining;
- contrast pairs;
- information gap;
- mini dictation / reconstruction;
- complete a dialogue;
- choose + justify;
- build from prompts;
- grammar maze / decision path;
- replace the wrong form;
- rephrase with target structure.

**Kasuta**
- role-play;
- problem-solving scenario;
- compare two options;
- mini consultation;
- voice-note style monologue;
- message/email;
- complaint/request;
- planning task;
- interview;
- negotiation;
- story continuation;
- explain a choice;
- mediation from a table/ad/timetable;
- unexpected-condition task.

### 12.5 Variation does not mean randomness

Variation must still serve the same:
- lesson goal;
- module grammar spine;
- lexical cycle;
- CEFR stage.

The author must not introduce novelty only for entertainment. Every format choice must have a didactic reason.

### 12.6 Module-level pattern

Within one 5-lesson module:

- Lesson 1: discovery-heavy, more support.
- Lesson 2: form contrast + guided practice.
- Lesson 3: transformation + mixed retrieval.
- Lesson 4: problem solving / freer interaction.
- Lesson 5: assessment with mixed formats and minimal support.

This gives learners repetition of content **without repetition of the same worksheet template**.

### 12.7 Visual variation

Across lessons rotate:
- full-width vs paired half-width blocks;
- text + support sidebar;
- two balanced task cards;
- table / timeline / dialogue layout;
- scenario card + response area;
- vocabulary panel integrated next to the task instead of always as a separate full-width list.

Large empty areas are still forbidden. Visual variation must improve learning density, not create decorative whitespace.

### 12.8 Quality check before publication

Before publishing a module, compare all five lessons side by side.

Reject the module if:
- three or more lessons share almost the same block order;
- the same exercise type appears in the same position repeatedly;
- the same page composition is reused mechanically;
- productive tasks differ only by topic nouns;
- the student could predict the whole worksheet layout after seeing one lesson.

A module passes only if it has **content continuity + format diversity**.
