# KeeleSepp CRM v2 design system

## Direction

CRM v2 is a calm, precise working environment for a language school. It should feel welcoming without looking like a
children's application and operational without looking like generic accounting software. The visual hierarchy must
help staff answer three questions quickly: where am I, what needs attention, and what can I do next?

## Foundation

- Deep navy frames navigation and establishes focus.
- KeeleSepp green is reserved for primary actions, current location and positive progress.
- Warm amber is a restrained secondary accent, not a default status colour.
- White and cool-grey surfaces separate working areas without excessive borders.
- Manrope is used for display hierarchy; DM Sans is used for readable operational text.
- Desktop pages favour useful density. Mobile pages stack actions and preserve touch targets of at least 44 pixels.

## Component rules

- One clear page title and one primary action per working surface.
- Cards group a task or decision, not arbitrary fragments of text.
- Tables remain the default for comparison; mobile views use dedicated cards rather than compressed tables.
- Status uses both text and colour. Colour alone never carries meaning.
- Empty, loading, error and success states use the same spacing and hierarchy across features.
- Motion is subtle, functional and removed when the user requests reduced motion.

## Migration rule

The visual foundation applies only to CRM v2. The operational v1 interface remains unchanged until the matching v2
workflow is functionally complete, role-tested and approved for gradual migration.
