# B1 noorkeele õppija — модуль 1 «Uus kool, uus algus» (b1noor-001…005)

Отдельный курс для подростков и 9 класса (ключ `b1noor`), рядом с «Eesti keel B1» — текущий курс a2b1 не тронут.
Файл: `crm-v2/src/features/worksheet-generator/admin/course/b1noor/module01.js`, дизайн v3 stations.

**Цель модуля.** Ученик представляется в новом классе / кружке, задаёт вопросы, рассказывает о своей неделе и
записывается в кружок. **Финал:** представиться в кружке + анкета регистрации (Harno W1a) и ответ руководителю в
Stuudium. Грамматика: вопросы (kas / вопросительное слово), настоящее время и отрицание, порядок слов после «Esmaspäeval…»
(I); местные падежи и партитив после отрицания — повтор A2.

## 10 правил

| Правило | Где | ✓ |
|---|---|---|
| Медиация | 003 ст. 3 (объяснить Дарье объявления) | ✓ |
| Онлайн-переписка | 004 ст. 5 (ответ руководителю в Stuudium) | ✓ |
| Четыре пряди | отмечены на странице учителя каждого урока | ✓ |
| Беглость ×2 | 002 ст. 4, 003 ст. 4 (новый слушатель / канал, без повтора монолога) | ✓ |
| Грамматика ≤ 10 мин + в финале | 002 вопросы, 003 порядок слов, 004 наст. время/отрицание | ✓ |
| Обратная связь на странице учителя | 2–3 цели, сначала подсказка, без перебивания | ✓ |
| Дом 10 + 1 | «Harjuta» 10 мин ≥ 4 дней + реальное задание на выбор | ✓ |
| Чередование / повтор | вопросы + местные падежи (A2) + партитив после отрицания; слова 002 → 003–005 | ✓ (модуль 1: «два модуля назад» = база A2) |
| Тексты ≤ 120 слов, цикл аудирования | цикл в инструкции + карточка учителя | ✓ |
| Произношение ×2 | 002 ст. 3 (Q2/Q3 kooli/linna), 004 ст. 3 (õ/ö/ü) | ✓ |

9 класс: в 005 — вступительные темы устной части экзамена (хобби, каникулы, планы, родной город, семья, школа).

## Сомнительные места

- Ударение и порядок слов: «Reedel ma lähen» тоже грамматично; правило подано как «обычно», не как ошибка.
- Вход 001 взят у взрослого курса (Sofia, офис) — подростковая версия входного теста не написана.
- Аудио нет (`audio: 'pending'`): учитель читает тексты; записать — `node tools/listening-audio/build.mjs`.
- Картинок нет; брифы не писались.
