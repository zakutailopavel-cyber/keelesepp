# B1, модуль 12 — пилот «станции»: было → стало

Каждый урок теперь — 4–6 независимых станций по 8–15 минут, у каждой свой маленький материал. Любую станцию можно
пропустить или переставить. Во всём модуле только одно задание зависит от другой станции (058, станция 6), и для него
на листе напечатана карточка-замена. У каждого задания есть строка «зачем» (кто, для кого, какой результат). У каждого
урока есть страница учителя: ядро на 45 минут, альтернатива, «если мало времени», типичные ошибки.
Урок 060 (пробный экзамен) не менялся. Блоков в уроке: было ~24, стало 11–13.

**056 «Погода меняет планы»** — финал: *решить*
- Было: «Mäletad?» → тема → радиопрогноз с цифрами → правило → сортировка → монолог → 8 мин письма | формы → экзамен L2 → страница метеослужбы → факты → пересказ «языком прогноза» → инфо-гэп | автоответчик Виктора → звонок в сельский дом → запись дома → письмо Лене → рубрика → самооценка (весь Kasuta висит на одном автоответчике).
- Стало: 1 страница темы + заметки нового коллеги + разговор с «коллегой» · 2 радиопрогноз (цифры) · 3 практикант радио: заметки → фразы, ответ слушателю · 4 экзамен L2 · 5 приложение погоды + спор с Виктором → решение в семейный чат.

**057 «Гроза на болоте»** — финал: *объяснить*
- Было: «Mäletad?» → научпоп → рассказ (одна длинная история, на ней всё) → разговор Оскара → правило → таблица → порядок слов → пересказ 2 раза | сочетания → статья R2 → факты → объявления → текст с банком → соединение → исправление ошибок → 2 круга вопросов | дневник Оскара → где искать → запись дома → конец рассказа → правка.
- Стало: 1 «Что такое болото?» (экзамен R2) + интервью журналисту · 2 хронология Виктора + звонок бабушки · 3 доска объявлений тропы · 4 голосовое Оскара → нормальные предложения · 5 где искать Муки (ранжирование с соседом) → пост в группу деревни.

**058 «Буря: почему и что потом?»** — финал: *пожаловаться*

- Стало: 1 правило + письмо Виктора с ошибками · 2 новость о буре + совет коллеге · 3 экзамен R3a (советы Päästeamet) · 4 забор с Юло (договориться) · 5 голосовое Виктора: список убытков + сообщение Хельги · 6 звонок в страховую, которая отказала (единственная зависимость; есть карточка-замена).

**059 «Зелёный двор»** — финал: *договориться*

- Стало: 1 радиоинтервью о биоотходах · 2 модель мнения + опрос председателя (учитель) · 3 сортировка для нового соседа · 4 объявление Тийны в подъезд · 5 приглашение на талкуд · 6 три предложения → договорённость в 300 € (экзамен S1b).
