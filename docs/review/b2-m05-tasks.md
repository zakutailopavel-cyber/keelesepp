# B1→B2, модуль 5 — по задачам (TBLT): было → стало

Модуль переделан по образцу модулей 1–4 (v4, `docs/COURSE_DESIGN_STATIONS.md` §7). Тема модуля — мнение и аргумент.
Раньше всё держалось на одной истории: София в дебат-клубе «Arutelukohvik», школьная форма в школе Kase, трамвай в
Каламае, четырёхдневная неделя в Tuul Logistika (эта тема уже есть в модуле 1). Теперь ученик спорит о настоящих,
спокойных эстонских вопросах своей жизни: переводить ли часы, какую ёлку ставить, сколько экрана ребёнку, как ездить
на работу. Политики, языка и национальных тем нет — для русскоязычного ученика это важно.

**Цель модуля для ученика:** «Ma oskan oma arvamust öelda, põhjendada ja teise arvamusega viisakalt arvestada».
**Продукт модуля:** карточка «Minu seisukoht» (свой настоящий спорный вопрос: уверенность, два аргумента, ответ другой
стороне, сравнение двух решений) и одноминутное выступление с ней в уроке 025 (часть S1 экзамена).

Грамматическая линия модуля сохранена и идёт по спирали: степень уверенности (021) → связки аргумента и глагол на
втором месте (022) → уступка и смягчение kuigi / siiski / ometi, ma pakuksin, kas poleks (023) → сравнение võrreldes /
erinevalt / seevastu / mida … seda (024) → всё вместе на экзамене (025).
