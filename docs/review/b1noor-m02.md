# B1 noorkeele õppija — модуль 2 «Pere, sõbrad ja naabrid» (b1noor-006…010)

Файл: `crm-v2/src/features/worksheet-generator/admin/course/b1noor/module02.js`, дизайн v3 stations.

**Цель модуля.** Ученик объясняет, кто есть кто в семье и среди друзей, описывает людей, планирует праздник и
договаривается. **Финал:** приглашение / сообщение 40–60 слов с 4 пунктами (подготовка к Harno W1b) и описание людей,
чтобы выбрать одного. Грамматика: родительный падеж (принадлежность, с послелогами) и придаточные kes / mis /
kelle / mille (I / P); повтор модуля 1 — вопросы, настоящее время, отрицание, порядок слов.

## Сомнительные места

- Ударение в иностранных именах (Milana, Daria) в эстонской речи — на первом слоге; стоит проверить учителю-носителю.
- «pärast kella üht / ühte» обойдено; формы nõo, peo, õe, sõbra, naabri проверены (nõo — по word-forms.json).
- Факты станции 007/4 проверены по памяти (Sildaru — бронза 2022, Tänak — чемпион 2019, Alika — Евровидение 2023); перед публикацией сверить по ERR.
