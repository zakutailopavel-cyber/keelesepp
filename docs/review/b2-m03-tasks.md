# B1→B2, модуль 3 «Minevik ja kogemused» — по задачам (TBLT, v4): было → стало

Модуль сделан по образцу модуля 1 (`docs/COURSE_DESIGN_STATIONS.md` §7, `b2/module01.js`). Старый модуль держался на одной
истории (Софья в Риге, переезд библиотеки, Маркус и Виктор) и одном шаблоне. Теперь в центре сам ученик: его семейный стол,
его опыт в эстонской природе, его линия жизни, его ошибка.

**Цель модуля для ученика:** «Ma oskan oma minevikust selgelt ja huvitavalt jutustada». **Продукт модуля:** карточка
«Minu lugu» и выступление с ней на «вечере историй» в уроке 015 (часть S1 экзамена) + письмо в библиотеку (W1).

**Грамматика (по roadmap, спиралью, через открытие):** 011 lihtminevik = событие (сильные глаголы, ei + -nud) → 012
täisminevik = опыт / lihtminevik = событие с датой → 013 enneminevik = что было раньше (enne kui, pärast seda kui, selleks
ajaks) → 014 все три прошедших в одном рассказе + сожаление (oleksin pidanud) → 015 проверка.

5. **Реальные факты с источниками.** История картофеля и «kartulivabariik» (Postimees, ERR/Статистикаамет), TAI 2024;
