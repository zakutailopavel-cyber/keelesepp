# B1→B2, модуль 6 «Tööelu» — по задачам (TBLT): было → стало

Модуль переделан по образцу модулей 1–4 (v4, `docs/COURSE_DESIGN_STATIONS.md` §7). Это первый **тематический** модуль:
работа — тема всех четырёх уроков. Правило v4 «работа не больше одного раза в модуле» писалось для общих модулей,
поэтому добавлено правило для тематических: модуль объявляет `MODULE.theme: 'work'`, и каждый урок с этой темой обязан
иметь свою подтему (`subtopic`), все разные. Без темы всё по-старому. Записано в §7.1 п. 7 и в таблице §7.3, проверка —
`v4TopicProblems` (stations.js), тесты — `v4Gates.test.js` (с темой / без темы / нет подтемы / одинаковые подтемы).

**Цель модуля для ученика:** «Ma oskan tööelus enda eest seista: räägin oma kogemusest, kontrollin lepingut, lahendan
tüli ja kaalun oma väikest äri». **Продукт модуля:** карточка «Minu tööelu kaart» и выступление 1 минута с ней в
уроке 030 (часть S1 экзамена).

Уровень модуля в файле теперь **B1+**, как в дорожной карте (`levelStage` B1+ у всех уроков 021–030); старый файл
писал B2-, это расходилось с картой.
