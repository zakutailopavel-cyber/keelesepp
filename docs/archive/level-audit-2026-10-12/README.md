## Системные проблемы (повторяются во всех курсах — значит, в шаблоне/генераторе)

1. **Задания решаются без знания языка.** Неверные варианты другой части речи или абсурдные; правильный — самый длинный;
   банк слов = числу пропусков; ответ стоит в подсказке; true/false выдают слова «alati / ainult».
2. **Нерешаемые задания.** Wordforms без указания нужной формы; categorize с одинаковыми списками (A2); таблицы без данных.
3. **Неверные ключи и «ложные ошибки».** Правильный эстонский помечен как ошибка в errorfix; правило порядка слов
   (kuna / mistõttu / sellepärast) в одних модулях одно, в других противоположное.
4. **Чтение короткое и буквальное.** Ответ списывается из текста; форматов Harno (утверждения ↔ абзацы, пропуски с 3–4
   вариантами, банк предложений с лишним) нет ни в одном курсе.
5. **Аудирования почти нет**, а на экзамене это четверть баллов. Вместо него диктант и перевод с русского в каждом листе.
6. **Грамматика ниже уровня.** На B2 и C1 снова тренируются kus/kuhu/kust, ma/da, прошедшие времена.
7. **Метка уровня врёт.** В курсе A2→B1 шапка Avasta пишет «B1», а содержание A2; Harjuta/Kasuta того же урока — A2.
8. **Языковые ошибки в текстах и ключах** — десятки, перечислены в файлах по уровням.

## Нормы в коде, которые расходятся с Harno (`didactics/levels.js`)

- C1: письмо 250–400 слов → по Harno ~180 и 220–260; чтение до 900 → ~600; монолог → 2 мин + дискуссия.
- B1: письмо до 180 слов и выводы из текста → по Harno ~50 + ~100 слов, выводы с B2.
- Банк слов «нет» на B1–B2 → по Harno есть банк фраз/предложений, но с лишними вариантами.
- Грамматика A2 занижена: по официальному описанию многие формы, которые у нас «B1», на A2 уже начинаются.
- Автопроверка ловит «слишком сложно», но не «слишком легко» и не качество вариантов ответа.

## Что исправлять в первую очередь

4. Метка уровня в шапке: этап урока (A2, A2+ …) отдельно от цели курса.
