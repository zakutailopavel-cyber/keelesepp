## 3. Оптимизация процессов

1. **Утро администратора — одна страница «Сегодня сделать».** Сейчас задачи разбросаны: неотмеченные уроки, «Ei saa tulla?»,
   новые заявки, долги, ученики без времени, родители без привязки. Одна карточка на Ülevaade со счётчиками и кнопками «открыть».
2. **Отметка урока в один клик в конце урока.** У учителя после урока (Live Classroom → «Lõpeta tund») сразу «Tund toimus» +
   тема по курсу. Неотмеченных уроков было 71 за две недели: это прямая потеря выставленных счетов (календарь за октябрь 5958 €, по счетам 2231 €).
3. **Счета из календаря автоматически раз в месяц** (черновики, бухгалтер только проверяет). Деньги считаются от проведённых уроков, как на новом дашборде.
4. **Сбор «Sobivad ajad» одной кнопкой**: список учеников без времени → «Kopeeri lingid» / отправка через админ-кнопку
   (правило: исходящие родителям — только через админа).
5. **Новый ученик: короткий путь** «заявка → тест уровня → пробный урок → карточка → время → расписание» как чек-лист на заявке
   в «Päringud» (сейчас каждый шаг в своём месте).
6. **Конец месяца**: автоматический отчёт родителю (уже есть кнопка у админа) + напоминание учителю закрыть отметки до 1-го числа.
